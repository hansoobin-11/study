웹서버(HTTP Server)
 - 클라이언트가 요청한 정적인 컨텐츠(Static Content)를 HTTP Protocol을 통해 처리하는 서버
   - URL(Uniform Resource Locator) : 웹에서 접근 가능한 자원의 주소를 표현하는 표준 방식
     - 정적 컨텐츠(HTML, Image...) 는 상대경로 / 동적 컨텐츠는 쿼리 스트링을 통해 서버에 전달 
   - URI(Uniform Resource Identifier / 통합 자원 식별자) : URL은 URI에 위치 개념을 추가한 것으로 URI가 더 포괄적 개념
- ex) Apache HTTP Server, NGINX, Microsoft IIS(Internet Information Server)
---------------

WAS(Web Application Service) 
 - 웹서버로부터 오는 동적인(Dynamic) 요청을 처리하는 서버
   - 동적인 데이터들을 처리하여 정적인 페이지를 생성해주는 소프트웨어 모듈인 웹 컨테이너(Web Container)를 포함
   - CGI(Common Gateway Interface)의 한계(프로그램 제어, 프로세스 문제 등)
   - 미들웨어(Middleware) 개념을 도입하여 Through Pass를 통해 별도의 서버로 업무를 이관하고, 그 서버에서 동적 요청을 처리
   - 웹서버와 여동하여 여러대의 WAS 운영을 통해 Load Balancing을 구현
     - 부하 분산 처리
     - 장애 발생 시 서비스 중단 없이 장애를 유발하는 WAS 제거 또는 교체 가능하므로 무중단 서비스 운영 가능
   - ex) 오픈소스 WAS : Apache Tomcat, WildFly / 상용 WAS : JBoss-EAP, Oracle WEBLOGIC, JEUS

---------------

프록시 서버(Proxy Server)
 - Proxy : 서버와 클라이언트 사이에서 대리로 통신을 수행하는 것
 - Proxy Server : 프록시 기능을 하는 서버

 - 역할
   - 캐시 데이터 사용
   - 보안
   - 접속 우회

 - 유형
   - 포워드 프록시(Forward Proxy)
   - 리버스 프록시(Reverse Proxy)

Apache HTTP Server 설치
 1. 다운로드 후 /conf/httpd.conf 수정
 2. 관리자 권한으로 cmd 실행 후 C:\Apache24\bin 으로 이동
 3. $httpd -k install - 윈도우 서비스로 등록
 4. 서비스 시작 : httpd -k restart(Apache HTTP Server가 시작) / 서비스 종료 : httpd -k stop / 버전 확인 : httpd -version
 5. 서비스 운영 중 httpd.conf 변경 시 웹서버 재시작
 * 서비스 : GUI 가 없는 프로그램을 백그라운드 서비스(서버용 프로그램)


클라이언트(웹 브라우저) -> 동적 요청 -> 웹서버 -> WAS(내부 웹서버 <-> 웹 컨테이너)
