- AI 강의
 - LLM(대형 언어 모델) + MCP(Model Context Protocol) + RAG(Retrieval-Augmented Generation) 를 통해 간단한 LLM 기반 어플리케이션 구성
 - RAG : LLM이 외부에서 정보를 찾아오는 도구
  - 질문 입력 시 외부 데이터베이스에서 관련 정보 찾은 후 LLM에 전달 + 답변 생성 --> 챗봇, AI 비서 등에 쓰임
 - MCP : 여러 모델 간 협업이 원활해지도록 도와주는 통신 규칙 ---> 멀티 에이전트, 복합서비스(챗봇 + 추천 + 데이터 분석) 등에 쓰임
 - LLM : 사용하는 언어 모델(ex : chatGPT-gpt-4 등)

- Devops
 - Build + CI/CD(Continuous Integration/Continuous Deployment) --->자동 배포 ---> 서비스가 가능한 Production 환경
 - docker로 어플리케이션을 container화
 - kubernetes : container들을 관리(Orchestration)
 - 컨테이너 -> 배포 -> 자동으로 전체 관리하기 위한 도구로 Jenkins와 GitHub Action 학습
