ex ) MyBatis(SQL Mapper) + Thymeleaf(Templacte 엔진)

- MyBatis
  - XML 사용
    ```xml
    <mapper namespace="com.board.mapper.BoardMapper">

    <!-- 게시물 목록 보기 -->
    <select id="list" parameterType="HashMap" resultType="com.board.dto.BoardDTO">
      select seq,seqno,title,writer,regdate,hitno from (select row_number() over (order by seqno desc)
          as seq,seqno, title, writer, hitno,regdate from tbl_board
          where title like '%'||#{keyword}||'%' or writer like '%'||#{keyword}||'%' or content like '%'||#{keyword}||'%')
   	  where seq between #{startPoint} and #{endPoint}
    </select>
    ```
  - @Mapper 인터페이스 (정교한 SQL 생성 어려움 -> 대형 프로젝트에서는 사용x)
    * 스프링 레거시 프로젝트에서는 @Mapper 인터페이스 사용 시 root.context.xml에 아래 코드 추가

      ```xml
      <mybatis:scan base-package="mapper 패키지 명" />
      ```
      
    ```java
    @Mapper
    public interface UserMapper {

    @Select("select id, name, email from users")
    List<User> findAll();

    @Select("select id, name, email from users where id = #{id}")
    User findById(Long id);

    @Insert("insert into users(name, email) values(#{name}, #{email})")
    int insert(User user);
    //int는 성공  여부에 따라 row 값 반환
    }
    ```
- JdbcTemplate (스프링 자체 객체)
  - 생성자 주입 방식으로 의존성 주입 -> 스프링빈으로 생성
    ```java
    public class UserRepository {
      private UserRepository(JdbcTemplate jdbcTemplate){
        this.jdbcTemplate = jdbcTemplate;
      }
    }
    ```

  - 데이터베이스 결과를 자바 객체로 변환해주는 클래스 생성
    ```java
    private final RowMapper<User> userRowMapper = (rs, rowNum) -> {
      User user = new User();
      user.setId(rs.getLong("id"));
      user.setName(rs.getString("name"));
      user.setEmail(rs.getString("email));
      return user;
    }

    public List<User> findAll() {
      String sql = "select id, name, email from users";
      return jdbcTemplate.query(sql, userRowMapper);
    }

    public User findById(Long Id) {
      String sql = "select id, name, email from users where id = ?"
      return jdbcTemplate.queryForObject(sql, userRowMapper, id);
    }

    public int save(User user) {
      String sql = "insert into users(name, email) values (?,?)";
      return jdbcTemplate.update(sql, user.getName(), user.getEmail());
    }
    ```

### Oracle 의 rownum
  - 쿼리 결과로 나오는 각각의 행(Row)에 부여되는 가상의 순번
    * 작동 방식 : 행을 하나씩 읽어와서 where 조건을 만족하는 순간에 rownum을 1번부터 번호를 부여(행이 하나씩 생성될때마다 rownum 증가)
