# Jenkins, GitHub Action을 통한 CI/CD

## Jenkins

### Docker를 이용한 Jenkins 설치

  1. docker 명령(Ubuntu에서)
   ```cmd
  docker run -d --name jenkins \
  -v /home/xavier/.kube:/var/jenkins_home/.kube \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /usr/bin/docker:/usr/bin/docker \
  -v $(which kubectl):/usr/bin/kubectl \
  -v /home/xavier/jenkins_home:/var/jenkins_home \
  -p 9000:8080 -p 50000:50000 \
  --group-add $(stat -c '%g' /var/run/docker.sock) jenkins/jenkins:lts
   ```
##### cf. jenkins:lts 의 내부 JDK는 21 버전 사용

  2. docker logs jenkins 명령으로 로그에서 Unlock 암호 확인 후 저장
  3. localhost:9000 주소로 접속(저장한 암호 사용)
  4. 플러그인 설치
  5. 교재의 JNLP(자바 웹스타터) 방식은 생략/Jenkins Permanent Agent(SSH 연결) 방식만 사용
  6. 개인키 가져와서 SSH 방식의 Agent Node 생성 및 Agent Node가 작업할 디렉토리 구성(ex : /home/milky/jenkins_project)
  7. docker 플러그인 설치
  8. 도커, 깃허브, 슬랙 보안 설정 등록

### jenkins project 디렉토리 구성 예시(gradle 버전 8.5 이상)

```
boardnext ----- .git                           
                       |     .gitignore
                       |     Jenkinsfile(젠킨스 설정 파일)
                       | - .github
                       |        | -- workflows
                       | - restapi
                       |        | --  
                       | - docker
                       |        | -- apache2
                       |        | -- boardrest
                       | - kubenetes 
                       |        | -- apache2.yml, boardrest.yml, ingress.yml, ...
```
### Jenkins 구성 시 생성되는 디렉토리 

 - jenkin_home --> Jenkins 설정 내용 저장
 - jenkins_board --> Agent working 디렉토리
